# Orush Car Showroom — Website + Admin Panel (Demo)

A cinematic, sale-ready car showroom website system with an admin panel, built as a white-label product: every showroom that buys it gets its own name, branding, city and data from the Admin Settings.

**Live demo (GitHub Pages):** https://talhaislamjadoon.github.io/orush-car-showroom/

## What's inside

- Cinematic public website — driving-car hero, pinned Sedan → SUV → Hatchback showcase, exploded car view, marquee, Day/Night toggle
- Full inventory with search & filters, car detail pages with specs and features
- **Color Studio, two modes:**
  - *Naya Model* (dealers/companies): per-colour real photos of the exact model; the selected colour flows into the enquiry as an order
  - *Asal Unit* (used-car showrooms): the car's own photos gallery with angle checklist, plus a clearly labelled "Rang Ka Andaza" reference-colours section
- Scroll-driven Interior Tour (5 steps), 2-car Comparison with Quick Faisla, Finance/EMI calculator
- Test Drive booking, trade-in and enquiry forms, Offers, Gallery, floating WhatsApp
- **Admin Panel** — dashboard, cars add/edit/delete with Sold/Featured marking, two car modes, Website Checklist with AI photo health check, enquiries inbox, theme schemes (5 presets) and full showroom identity settings
- **AI photo responsibility** — the AI sources exact-model factory colours, studio angles and interiors, load-verifies every photo before saving, keeps checking and repairing broken photos, and keeps filling empty photo slots; manual entries always win
